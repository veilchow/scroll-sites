# BLOOM · 菌丝秘境（v2 · 连续世界引擎 + P1 交互反馈层）

一次**由滚动驱动**的下潜旅程：滚动进度 0–100% 连续驱动**一台相机**在一张竖幅剖面全景长图内下移——从暮色森林地表，穿过巨菇伞盖，沉入发光的菌丝网络深处。**一镜到底：全程无换图、无交叉淡化、无硬切**（CONTINUITY-SPEC v2）。在此之上，**P1 反馈层**（`bloom-feedback.js`，见 INTERACTION-DESIGN §2）提供计量 HUD、穿越时刻、WebAudio 声音系统与速度响应——网页在回应每一次滚动。

> v1 的问题：三个独立场景函数 + 交叉淡化，滚动时画面是"切换"而非"镜头运动"。
> v2 的原则：**一个连续世界 + 一条相机路径**；章节只是 UI 标记，画面参数不随章节跳变。
> P1 的原则：**反馈是叠加层**——`bloom-app.js` 只打 4 个一行钩子（`BLOOM_FEEDBACK` 缺席时零影响），引擎只接受一个可选 `fr.speed` 参数（默认 0 时渲染位级不变）。

## 运行方法

任意静态服务器即可：

```bash
cd scroll-sites/bloom
python -m http.server 8803
# 浏览器打开 http://127.0.0.1:8803/
```

无依赖、无构建；唯一的外部素材是 `assets/forest-well.png`（729×2158，约 3.3MB）。

## 世界与相机模型（核心）

主图层 `assets/forest-well.png` 是**一整张连续图**（从上到下：暮色地表 → 巨菇伞下空间 → 菌丝网络深处，实测地理：地表 0–19%、伞盖边缘 ≈19–21%、青碧伞下 19–46%、土壤暗带 46–66%、菌丝网络 66–100%、母核暖光质心在图内 (51%, 87.4%)）。滚动进度 `p ∈ [0,1]` 只驱动相机参数：

### 相机路径参数表（`bloom-scenes.js` `cameraAt()`，纯函数）

| 参数 | 定义 | 说明 |
| --- | --- | --- |
| cover 基准 | `bs = max(W/729, H/2158)` | `object-fit: cover` 语义：宽对齐铺满，高度余量即相机行程（桌面 16:9 约 5.3 倍视口高，手机竖屏约 1.4 倍） |
| 缩放 `s(p)` | `1 + 0.12·ss(0,0.5,p) − 0.08·ss(0.5,1,p)` | **1.00 → 1.12（p=0.5）→ 1.04**，C¹ 连续，全程 ≥1 → cover 永不露边 |
| 焦点 `fy(p)` | `fmin + (fmax−fmin)·p`，再夹取进 `[v/2, 1−v/2]` | 屏幕中心对应的**图高比例**，线性下移；`v0 = H/(图高·bs)`、`v1 = v0/1.04`，`fmin = v0/2`、`fmax = 1−v1/2`；夹取保证图幅等比/高度受限的零余量视口在端点也不露亚像素边 |
| 绘制矩形 | `x = (W−DW)/2`，`y = H/2 − fy·DH` | `DW/DH = 图宽高 × bs × s(p)`；**p=0 图顶贴视口顶，p=1 图底贴视口底** |
| 端点校验 | `sy(0) = 0`，`sy(1)+DH(1) = H` | 对任意视口几何精确成立（Node 自查断言） |

**章节只是 UI 标记**：ch1 = p 0–33%（地表）、ch2 = 33–66%（伞下）、ch3 = 66–100%（深处）；导航点击 = 平滑滚动到对应相机位（`p = i/3`），导航/标题/进度条随之切换，**画面本身连续**。

### p≈33% 穿越伞盖边缘（"穿过"的体感，不是切换）

前景层速度 1.3× 天然更快：一整片伞缘剪影（巨大椭圆弧 + 菌褶须 + 一线青碧荧光描边）在 `bell(p, 1/3, 0.042)` 窗口内快速掠过画面；叠加轻微亮度波动——先轻微变暗（遮挡投影，`crossing`），穿过后青碧微亮响应（`crossingLight = bell(p, 0.383, 0.05)`）。全部是 p 的连续钟形函数，无任何切换。

## 视差三平面（程序绘制，全部连续）

| 平面 | 速度 | 内容 | 实现 |
| --- | --- | --- | --- |
| 远景 | **0.7×** | 远处菌柱群剪影 + 薄雾带 | 共享预烘焙模糊精灵（7–12 实例，低透明度）+ 漂移雾带，行程带高度 `H + 0.7·shiftMax` |
| 主图 | **1.0×** | forest-well.png | 每帧一次 `drawImage`（相机矩形） |
| 前景 | **1.3×** | 菌柄 / 垂帘 / 蕨叶 / 根须剪影（半透明 + 预烘焙模糊） | 9–15 个剪影簇沿行程带 `H + 1.3·shiftMax` 分布；**种类随旅程连续更替**：蕨叶（地表段）→ 垂帘+菌柄（伞下段）→ 垂根（深处段），每簇有 smoothstep 的 p 可见窗，无跳变 |

## 氛围参数表（`atmosphere(p)`，全部是 p 的平滑连续函数）

| 参数 | 路径（p: 0 → 0.5 → 1） | 对应体验 |
| --- | --- | --- |
| `fireflies` 萤火密度 | **1.0 → 0.55 → 0.35** | 地表多 → 伞下中等 → 深处围绕母核（聚焦盒向母核投影点连续收拢，离屏权重连续归零） |
| `spores` 孢子漂浮 | 0.18 → **1.0**（伞下高原）→ 0.18 | 穿行孢子星尘 |
| `motes` 母核环绕尘埃 | 0 → 0 → **1.0** | 深处母核轨道尘埃 |
| `warmMix` 光色温（暖色占比） | **0.85 → 0.15 → 0.50** | 地表暮色暖光 → 伞下青碧 → 深处青碧+暖黄母核；每个粒子的暖↔青色按 smoothstep 连续混合，无瞬变 |
| `fog` 薄雾 | 0.55 → 0.30 → 0.16 | 地表雾气 → 伞下薄雾 → 深处沉降 |
| `dark` 下潜变暗 | 0 → 0.78（p≈0.66 峰）→ 0.45 | 穿过土壤暗带，母核随后照亮 |
| `vignette` 暗角 | 0.55 → 0.70 → **0.95** | 越深越暗，聚焦母核 |
| `crossing` / `crossingLight` | bell(1/3) / bell(0.383) | 伞盖穿越的暗/亮波动 |
| `waveGate` 光传导波强度 | 0 → 0 → **1.0**（ss 0.655→0.75 淡入） | 进入深处段（p>66%）后波的强度随 p 连续淡入 |
| `gradeWarm` / `gradeTeal` 色温分级 | 0.10 → 0 / 0 → 0.06 → 0 | 暖光/青碧的全屏低透明度分级叠层 |

**菌丝光传导波**（v1 保留）：滚动首次进入第三章时触发一次由屏幕边缘向母核的收敛光脉冲——收敛亮环 + 图内锚定的节点场波前逐个提亮（高斯波带命中），波及后的余辉渐熄；强度乘 `waveGate` 随 p 连续淡入。母核、节点场、尘埃均锚定**图内坐标**，随相机连续移动（滚动时波与母核在世界中固定）。

## 架构：统一场景渲染接口（为视频层预留）

```
backend = BLOOM.createBackend({ image, segments, video })
  .ready         Promise；素材就绪（失败也 resolve → 程序化兜底背景）
  .resize(env)   {w,h,area,minDim} → 重建视差层场与粒子（数量按面积缩放）
  .render(c,{p,time,W,H,DPR})  整帧绘制（上述九层顺序）
  .enterChapter(i,time)        UI 章节事件（ch3 → 触发光传导波）
  .dispose()
```

`bloom-app.js`（交互外壳）**只**通过该接口消费场景渲染。**视频 scrub 层预留**：若未来放入 `assets/segment-1.mp4` 与 `segment-2.mp4`（分别覆盖 p∈[0,0.5) / [0.5,1]，±0.02 重叠带 smoothstep 合成，每帧 `video.currentTime = 段内进度 × duration`），`createBackend({video:true})` 将返回视频后端，seek 未就绪/解码异常帧回退本 canvas 引擎同一相机位兜底——**本期仅留接口契约与 `probeSegments` 探测，未实现 scrub**。

## P1 交互反馈层（HUD · 穿越 · 声音 · 速度 · 待机）

`bloom-feedback.js` 实现 INTERACTION-DESIGN §2 的全部网页层反馈，经 4 个一行钩子接入外壳（`frame→tick`、`setChapter→onChapter`、`render 携带 speed`、`tourStep/reducedApply→通知`），引擎仅在 `render` 帧对象上多读一个可选 `speed`。

### 计量 HUD（左下，等宽大数字，每章一组，穿越时翻滚归零→新单位自下淡入 300ms）

| 章 | 大数字 | 小组件 |
|---|---|---|
| 01 地表（0–33%） | **环境光照 420→60 lx**（随暮色变暗） | 森林时间 19:42→19:58 缓慢走动 |
| 02 伞下（33–66%） | **孢子浓度 38→96 ppm**（断续 +2/−1 的活数字） | 距母核 22.0→6.0 m 倒数 |
| 03 深处（66–100%） | **下潜深度 0.0→8.4 m**（入土瞬间归零启动） | 光传导同步率 0→100%（smoothstep 随深处段爬升）；**100% 达成瞬间数字亮起 +「所有光，都连成一张网」淡入**（回退自动熄灭） |

数字显示值对目标做指数追逐，**速率随滚动速度加速**（快滚数字滚得快）；`prefers-reduced-motion` 下直切 + 淡入淡出。

### 穿越时刻（章界 ±1.5% 窗口去重，下行跨越触发，退到窗外重新武装）

| 时刻 | 组成 |
|---|---|
| **E · 穿伞盖（33%）** | 荧光簌簌 sting（8 簇高频短噪声 2.6–5.4kHz + 柔和衰减 + 高频闪光音）+ 全屏青碧脉冲 200ms + 画面微震 ±2px/150ms + HUD 切 ppm |
| **F · 入土（66%）** | 低沉闭锁 sting（噪声低通 760→60Hz 扫频 400ms + 次低频闷击 52→38Hz）+ 画面短暂变暗脉冲 + 微震 + 深度计 0.0m 启动 |

### WebAudio 声音系统（全合成零素材；首次用户手势才创建 AudioContext；M 键/静音钮全局静音）

三床环境音，章间 **800ms 线性交叉淡化**；前瞻调度器独立于 rAF（200ms 节拍器，静态模式/后台恢复不追帧）：

| 床 | 合成 | 参数 |
|---|---|---|
| 地表 | 虫鸣 + 轻风粉噪 | 虫鸣=2–4 声一组的高频正弦 ping（3.9–4.8kHz，间隔 0.55–2.45s，**速度快→密度高**）；风=Paul Kellet 粉噪 2s 环形缓冲 → 低通（**截止 600–3200Hz 随滚动速度开合**，增益 0.055–0.165） |
| 伞下 | 空灵垫 | F 泛音列 4 正弦（174.61/220/261.63/349.23Hz，±3–4 音分失谐），每声部独立慢 LFO（0.05–0.117Hz）幅度明灭=缓慢相位差 + 带通气流薄噪 |
| 深处 | 心跳 + shimmer | **60BPM** 低频 lub-dub 双跳（54Hz→46Hz）+ 36Hz 极低垫 + 1318/1975Hz 微弱 shimmer（慢 LFO） |

UI 音：导航/漫游 tick（1174.66Hz 短正弦）。页面隐藏时 ctx.suspend，恢复时 resume。

### 速度响应与待机

- 滚动速度（|Δp|/Δt 平滑，0.25 p/s 归一）→ **孢子拉伸 ×4.5 / 萤火 ×3.5**（引擎侧纵向拉丝）+ HUD 数字滚动加速 + 风噪滤波与虫鸣密度调制；
- 停留 3s → 底部呼吸提示「向下 ↓ 潜入伞下 / 向下 ↓ 深入菌丝 / 旅程尽头 · 光在等你」（按章换语），任何输入立即隐藏；自动漫游中不出现。

### 约束落实

- H/Esc 口播模式：全部新 HUD（`.ui` 类）隐藏，**声音保留**；
- `prefers-reduced-motion`：无微震、无 sting、无闪光、无活数字抖动，HUD 淡切、数字直切（静态模式下由滚动事件驱动 `tick`）；
- 移动端：HUD 压缩左下角（字号 clamp(22px,7vw,32px)），静音钮/待机提示同步收窄；
- 不破坏 v2 引擎：`render-smoke`/`continuity-check` 原样通过（无 `fr.speed` 时渲染路径不变）。

工程细节：DPR 适配（上限 2）、resize 防抖 160ms 整体重建、`visibilitychange` 暂停 rAF、粒子/剪影数量按屏幕面积缩放、页面加载态（主图解码前一颗呼吸光点）、图片加载失败自动退回程序化兜底背景（站点不白屏）。

## 静态模式（prefers-reduced-motion）

系统开启"减少动态效果"时自动进入：不跑连续动画，改为**同一长图三个相机位的取景 crop**——p=0.02（地表）、0.50（伞下，s=1.12 峰值取景）、0.94（母核），定格时刻 `time=7.7`（一切动画均为 time 纯函数，可任意定格）。章节间以快照淡入淡出切换；空格/漫游按钮逐章跳转。三个取景来自同一相机路径，天然连续。

## 自查（可复现）

```bash
node --check bloom-scenes.js bloom-app.js bloom-feedback.js
node tools/continuity-check.mjs   # 桩环境驱动 p 0→1 步进 0.001 × 15 种视口几何
node tools/render-smoke.mjs       # DOM+Canvas 全量桩，泵 rAF 走完整程（含 resize/波触发）
node tools/feedback-check.mjs     # P1 反馈层桩：计量插值/章界去重/AudioContext 手势门控/同步率映射
python -m http.server 8813        # curl 首页/资源 200、DOM 标记检查后关闭
```

连续性自查结论：相机参数连续（单步 |Δsy| ≤ 10.8px/0.001p、|Δscale| ≤ 3.6e-4，均为正常滚动的平滑量级）、cover 任意视口不露边（含图幅等比零余量视口，端点亚像素对齐）、相机单调下移、scale 关键帧 1.0/1.12/1.04、氛围参数无跳变（|Δ| ≤ 0.016/步）、crossing 峰值 p=0.333。

反馈层自查结论：六个计量插值起止精确（420→60 / 19:42→19:58 / 22→6 / 0→8.4 / 0→100% / 38→96）；章界 ±1.5% 去重（窗口内单次、窗外重武装、纯回退不触发）；AudioContext 手势前 0 实例、手势后 1 实例且幂等；同步率显示≡纯函数映射，p=1 达 100% 点亮 + 结语淡入、回退熄灭；E/F 各触发一次并施加正确的闪光/微震类。

## 已知限制与取舍

- 主图 3.3MB PNG，首次访问需一次解码（加载态呼吸光点过渡；建议生产环境换 WebP/AVIF 可再省一半以上体积，文件名在 `createBackend` 参数处可配）；
- 竖长图在手机竖屏 cover 下可见图高占比大（约 73%），章节的画面差异在窄屏上弱于桌面——由氛围层与 UI 标记补偿；
- 视频分段 scrub 层未实现（接口与探测已留，见"架构"节）；
- 极旧设备（无 GPU 合成的 Canvas）帧率可能下降，可调低 `buildWorld` 中粒子密度分母缓解；
- 声音需首次点击/按键/触摸解锁（浏览器手势策略；纯滚轮不构成手势），此前反馈层其余部分照常工作；
- 待机提示按 `performance.now()` 计时，标签页后台节流时会延迟出现（无功能影响）。
