# NEON DRIFT / 雨夜漫游（v2 · 一镜到底 + P1 反馈层）

滚动驱动的叙事网站：**整站只有一张图、一条相机路径**。主素材 `assets/city-tower.png`
（724×2172 竖幅城市剖面全景）以 `object-fit: cover` 语义铺满视口，滚动进度
`p ∈ [0,1]` 连续驱动相机在长图内从图顶（雨夜高空）移动到图底（地下市场），
叠加连续的 scale 推轨——**无换图、无交叉淡化**，滚动就是镜头在运动。

v1 的"三张独立构图插画 + 交叉淡化"已按 `../CONTINUITY-SPEC.md`（v2 连续性规格）
重构淘汰；交互外壳（滚动映射 / 导航 / 漫游 / 键盘 / 静态模式）全部保留。

**P1 反馈层**（依 `../INTERACTION-DESIGN.md` §2，本周期新增）：在连续相机之上叠加
"网页在响应我"的可感知反馈——计量 HUD（海拔计/门牌步数/楼层翻牌/温度/距离倒数）、
两个穿越时刻（33% 穿云落地 / 66% 沉入地下）的多感官瞬间、WebAudio 全合成三床
环境音、滚动速度响应（雨丝斜拉/数字加速/楼隙掠过光带）、3s 待机呼吸提示。
视频缺席时交互反馈已完整成立（P2 视频 scrub 接入后反馈层原样保留）。

## 运行方法

方式一：直接双击打开 `index.html`（file:// 可运行，唯一素材为同目录图片，无 fetch/XHR）。

方式二（本地服务器）：

```bash
cd scroll-sites/neon
python -m http.server 8802
# 浏览器访问 http://127.0.0.1:8802/
```

## 相机模型（核心）

主图以宽度铺满视口（cover 语义，图高约 3 倍视口高），`p` 连续映射相机：

| 参数 | 映射 | 说明 |
|---|---|---|
| `cover` | `max(W/724, H/2172)` | 与 `object-fit: cover` 等价；保证 `dw≥W、dh≥H` 恒成立 |
| `zoom(p)` | `1.0 → 1.15 → 1.05` | 两段 smoothstep 拼接（C1 连续）：`1 + 0.15·ss(p/0.5的区间) − 0.10·ss(后半)`，p=0.5 恰为 1.15 |
| 相机中心 `cy` | 图像素 `lerp(vh/2, 图高−vh/2, p)` | `vh = H/scale` 为视口可见图高；p=0 图顶贴合视口顶，p=1 图底贴合视口底 |
| `translateY` | `dy = H/2 − cy·scale` | 恒 ∈ `[H−dh, 0]`，任意视口尺寸不露边（代数可证，测试断言） |
| `travel(p)` | `cy·scale − H/2` | 相机已下移的屏幕像素，常规视口下单调不减 |

视差三平面（程序绘制，全部连续）：

| 平面 | 速度 | 内容 |
|---|---|---|
| 远景 | **0.7×** | 雨云（高空段）、远处楼群灯火（screen 叠加微闪烁，入地淡出） |
| 主图 | **1.0×** | `city-tower.png` 相机取景；动态元素锚定图像坐标 |
| 前景 | **1.3×** | 掠过的楼体边缘剪影、霓虹汉字招牌、街灯局部（半透明 + 叠影 = 焦外感） |

主平面动态元素锚定**图像坐标**（随相机移动，属于画面世界）：高空飞行器光轨
（图 3–22% 高度带）、街面车灯与撑伞人流剪影（图 44–50% 路面带）、地下蒸汽与
弧垂灯串（图 79–95% 市场带）。强度随 `p` 连续淡入淡出，不硬切。

## 交互（v1 全部保留）

| 操作 | 行为 |
|---|---|
| 滚轮 / 触摸 / 拖动滚动条 | 连续 scrub 相机（带轻微阻尼缓动，停滚即停）；**快滚有快滚的样子**（雨丝斜拉、HUD 数字加速、声音更呼啸） |
| 顶部导航「高空 / 街面 / 地下」 | 平滑滚动到对应相机位（p=0 / 1/3 / 2/3），滚动时高亮当前章，跳章有 tick 音 |
| 空格 或「▶ 自动漫游」 | 约 45 秒走完全程的自动漫游（任意滚轮/触摸/方向键立即中断；空格为播放/暂停；启停有确认音） |
| H 或 Esc | 隐藏 / 恢复全部 UI（口播模式，场景与声音继续） |
| **M** 或「♪ 音效」钮 | **全局静音切换**（按钮与按键共享状态指示） |
| ↑ ↓（及 PageUp/Down、Home/End） | 滚动 |
| 首次滚动 / 点击 / 按键 | 手势初始化 AudioContext（此前不创建、不出声） |
| 停留 3 秒 | 底部呼吸提示「继续下落 ↓ / 继续前行 ↓ / 再往下 ↓」（按章变化，任何输入立即隐藏） |
| 系统开启「减少动态」 | 静态模式：同一长图在三个相机位（p=0.15/0.50/0.86）的取景 crop + 章节间淡入淡出，禁用连续动画、自动漫游、微震与 sting（HUD 淡切） |

其他 UI：左侧大标题随章节淡入淡出；右侧竖向 0–100% 探索进度条（带 1/3、2/3 刻度
与实时百分比）；底部滚动提示在首次滚动后淡出；`#fx` 层静态暗角 + 细扫描线
（canvas 内另有随 p 连续变化的动态暗角与色温）。

## P1 反馈层（INTERACTION-DESIGN §2 全项）

### 计量 HUD（左下角，随章节状态机切换组件集）

| 章 | 组件 | 行为 |
|---|---|---|
| SEG1 高空 (0–33%) | **海拔计 480m→30m**（大数字）+ 垂直速度 | 随进度连续插值（1 位小数）；速度经平方压缩映射到 0–88 m/s 的可信下坠区间 |
| 穿越 C (33%) | → **「街道定位：中山路 · 路口07」** + 伞图标 | 旧计量翻滚退场 240ms → 新组件从下淡入 300ms；伞"落地收起"动画（触地下压 → 伞面收拢 → 手持摆动） |
| SEG2 街面 (33–66%) | **门牌 07→19** 滚动 + 步数计数 | 门牌随进度插值（两位补零），步数 0→486 单调映射 |
| 穿越 D (66%) | → **楼层翻牌 B1→B2**（机械整牌翻转，双咔哒）+ **温度「地表 12° → 地下 18°」** | 翻牌 rotateX 580ms 带回弹与铰线；温度数字滚升 + 标签切换 |
| SEG3 地下 (66–100%) | **距核心面档 12m→0m** 倒数 | p≥99.5% 抵达 0m，**「已抵达 · 城市的心跳」**暖光亮起（呼吸辉光） |

### 穿越时刻（与连续相机路径协同，进度越界瞬间触发）

| 时刻 | 声音（WebAudio sting） | 视觉 |
|---|---|---|
| **C · 穿云落地** (33%) | 雨声音量跳升（×2.4，约 1.1s 回落）+ 宽带雨泼溅 + 82→36Hz 落点闷响 | 霓虹饱和度脉冲（saturate 1→1.8→1，550ms）+ 冷色 flash + ±2px/150ms 微震 + HUD 切换 |
| **D · 沉入地下** (66%) | 雨声闷掉（低通 6200→240Hz 扫频 400ms，市井同步闷化）+ 96/144Hz 正弦对过卷积混响 + 关门 slam | 色调冷→暖 flash + 微震 + HUD 翻牌/切温 |

触发去重：探测器带 ±1.5% 滞回窗，阻尼缓动在界线附近的抖动不会重复触发；
退回窗外重新武装后再次向下穿越才会重放（回退方向只切 HUD 不重播 sting）。

### 声音系统（audio.js，全合成零素材）

三床环境音按章交叉淡化（`setTargetAtTime` τ=0.28 ≈ 800ms 到位）：

| 章 | 音床 | 合成 |
|---|---|---|
| 高空 | 粉噪风 + 偶发闷雷 | 粉噪→低通（cutoff 320–1820Hz 随滚动速度）；闷雷=棕噪 0.4× 低通 110Hz 爆发（峰 0.4–0.7、衰减 2.4–3.6s）+ 44→26Hz 次声层，9–22s 随机间隔 |
| 街面 | 密雨 + 模糊市井 | 白噪→高通（1450−520·v）→低通 6200，增益 0.12–0.33 随速度；市井=棕噪→低通 460（穿越 D 闷化至 190） |
| 地下 | 低通闷响 + 人声碎片 | 棕噪→低通 150（0.26–0.34）；人声=锯齿 96–154Hz 带音高漂移→双共振峰带通（F1 350–550 / F2 900–1400，Q6）→短包络断句（0.5–1.6s、2.8–7.3s 间隔、随机声像），过卷积混响（全合成指数衰减 IR 1.8s） |

- **首次用户手势**（滚轮/触摸/指针/按键/点击）才创建 AudioContext，此前完全静默；
- **M 键 / ♪ 按钮**全局静音（主增益 90ms 斜坡归零，按钮状态指示）；
- **速度调制**：滚动速度 → 风噪 cutoff 与增益、雨声强度与雨点沉度、地下闷响（快滚更呼啸）；
- **UI 音**：导航 tick（1180/1760Hz 双短音）、翻牌咔哒（高通噪声 click + 1180Hz）、
  漫游启停双音（上行 620→930 / 下行 930→590）、抵达暖和弦（392/523/659/784 错峰进混响）；
- 页面不可见自动 suspend、回前台 resume。

### 速度响应（scene.js `setSpeed` + HUD）

- 雨丝：长度 ×(1+1.7v) 拉丝、倾角 +0.34v 斜拉、落速与横漂加快（快滚斜拉丝）；
- 楼隙掠过：新增 6 条 1.6× 平面速度光带（比前景 1.3× 更快、青/品红交替、长度与
  透明度随速度），SPD<0.12 不绘制；
- HUD：大数字 `.spd` 态（轻模糊 + 辉光增强）；音床同步调制（见上）。

### 约束遵循

- **H/Esc 口播模式**：HUD/待机提示/静音钮全部随 `body.ui-hidden` 隐藏，**声音保留**；
- **prefers-reduced-motion**：无微震、无 sting、无 flash，HUD 淡切、翻牌/收伞瞬时到位、
  待机提示恒定亮度、雨丝不响应速度（静态模式速度恒 0）；
- **移动端**：HUD 压缩至左下角（小号数字/门牌，含 safe-area 适配）；
- v2 引擎与既有交互未动（新增均为叠加层；`cameraFor/atmoFor` 未改，连续性测试原样通过）。

## 架构：基础层后端（为视频层预留）

场景渲染封装为 `NEON` 单一接口：`init / resize / tick / render`，以及
`cameraFor(p,w,h)`（相机参数）、`atmoFor(p)`（氛围参数，测试与调试用）、
`setSpeed(v)`（P1 速度响应入口）、`setBase(name)`（基础层切换桩）。

主图层的绘制走**基础层后端**统一契约 `{ ready(), draw(g, cam, alpha) }`，其余
（视差、氛围、动态元素）一律由本引擎叠加、不随后端变化。预留：若
`assets/segment-1.mp4` / `segment-2.mp4` 存在，可实现 `videoScrubBackend`
（p 前/后半段分别 seek 两段视频，seek 未就绪或解码失败时回退 `imageBackend`，
即"视频 scrub 优先、本引擎兜底"），经 `NEON.setBase('video')` 切换。
本期仅留接口与注释，见 `scene.js` 顶部「基础层后端」一节。

## 已知限制

- 视口高宽比超过素材的 1:3（极端长窄屏）时，cover 由高度决定、相机行程趋近 0，
  尾段收焦（1.15→1.05）时画面底部锚定并轻微回拉——连续、不露边，属该几何下的预期。
- 主图载入前渲染深夜渐变兜底，载入完成一次性淡入（素材预热，非滚动过渡）；
  载入失败则停留在兜底画面（氛围层照常工作）。
- 自动漫游在 reduced-motion 静态模式下禁用（按钮置灰提示「静态模式」）。
- 环境音仅在首次用户手势后可用（浏览器自动播放策略）；手势前的滚动只有视觉反馈。
- `AudioContext` 不可用（极老浏览器）时声音系统整体静默降级，站点其余功能不受影响
  （audio.js/feedback.js 缺失时 app.js 亦按空引用降级）。
- Safari 旧版无 `createStereoPanner` 时人声碎片退化为单声道（已做特性检测）。
