# ASTRA · 深空信标计划

一个**滚动驱动叙事网站**：全屏场景铺满视口，页面滚动进度（0–100%）被连续映射到"镜头时间轴"——向下滚动镜头推进，向上滚动回退，停止滚动画面即停。滚动条就是播放器。

v2（CONTINUITY-SPEC 连续性重构）：主图是三张**同轴构图剧照**（`assets/approach.png` → `port.png` → `core.png`，各 1672×941），由一条**连续相机路径**驱动；氛围层（前景剪影视差 / 星云薄雾 / 星尘 / 光色温）为纯程序化 Canvas 绘制。无任何 CDN/网络请求/构建步骤。

P1（INTERACTION-DESIGN §2 反馈层）：在 v2 引擎之上加入**顶层交互反馈层**——计量 HUD、穿越时刻（sting/flash/微震）、WebAudio 全合成声音系统、速度响应与待机提示。引擎相机路径与全部既有交互零改动。

P2（INTERACTION-DESIGN §3 画面层）：接入"**视频 scrub 优先、引擎渲染兜底**"的画面层——两个全关键帧 scrub 片段（`assets/seg1-scrub.mp4` / `seg2-scrub.mp4`，2K H.264 `-g 1`、6.584s、含音轨）把滚动进度映射到 `video.currentTime`；55%/75% 两处接缝藏在引擎光晕换图峰值时刻；任一段失败静默回退 v2 连续相机路径；自动漫游时 unmuted 顺序连播。P1 反馈层原样保留（与画面层解耦）。

- 品牌：**ASTRA / 深空信标计划**
- 章节导航：**接近 / 对接 / 点亮**

## 相机模型（v2 核心：一个连续世界 + 一条相机路径）

滚动进度 p ∈ [0,1] 是唯一驱动源；相机参数（scale / 放大中心 / 微平移）与氛围参数（光色温、星尘密度流速、薄雾、前景、暗角）全部是 p 的**连续平滑函数**。章节只是 UI 标记，画面参数不随章节跳变。

| 进度 | 阶段 | scale | 放大中心（图内归一化坐标） | 说明 |
|---|---|---|---|---|
| 0 → 0.545 | approach 连续 dolly-in | 1.00 → **3.00**（easeInOutCubic） | 对接港 **(0.500, 0.477)** | 放大中心 = 闸门在图中的位置（读图确认，硬编码） |
| 0.455 → 0.540 | 光晕①自然增强 | — | 对接港 | 进近发光闸门，辉光长大（动机） |
| **0.545 – 0.555** | **换图①** approach→port | 3.00 → 1.00 | (0.500,0.477)→(0.502,0.472) | 交叉加权严格发生在光晕①峰值平台内（约 0.45s@45s 漫游），切点藏在光里 |
| 0.555 → 0.625 | 光晕①衰减 | port 显影 ≈1.00 | 闸门中心 | 从匹配 framing 起继续推进 |
| 0.55 → 0.75 | port 连续推进 | 1.00 → **1.40**（easeInOutCubic） | (0.502, 0.472) | 闸门由约 70% 画幅 → 充满画面 |
| 0.700 → 0.740 | 光晕②增强（青白） | — | 闸门中心 | 闸门充满画面时辉光涌起 |
| **0.745 – 0.755** | **换图②** port→core | 1.40 → 1.05 | (0.502,0.472)→(0.500,0.390) | 青白光晕短暂充满全屏，切点藏在光里 |
| 0.755 → 0.830 | 光晕②衰减 | core 显影 1.05 | 晶体 | — |
| 0.75 → 1.00 | core 舱内漂移 | **1.05 → 1.25**（smootherstep） | 晶体 **(0.500, 0.390)** | + 极轻微平移 panX +0.010→−0.008、panY −0.006→+0.010（屏比例） |

全站仅上述两处换图，且均为**有动机的光晕过渡**（motivated transition）——换图前亮部自然增强到峰值，交叉加权窗口严格落在峰值平台（glow ≥ 0.98）内，随后光晕衰减显影下一张。不存在裸交叉淡化与硬切。主图以 object-fit: cover 语义铺满视口（宽度对齐），任意 p 处可见主图权重之和恒为 1。

## P1 反馈层（INTERACTION-DESIGN §1 ASTRA / §2）

网页层的"计量、状态、反馈、声音 UI"，与 v2 引擎的连续相机路径协同（**引擎文件零改动**，穿越 sting 恰在两次光晕换图的峰值时刻 55% / 75% 触发）。

### 计量 HUD（左下角，章集群互斥 300ms 淡切；移动端压缩为左下角一列小字）

| 段 | 组件 | 行为 |
|---|---|---|
| SEG1 0–55% | **距离计**（大数字） | 120.0km → 0.8km 连续插值；显示值带速度自适应追赶（快滚数字加速滚动） |
| | 接近速度 | 基值随进度衰减 × 滚动速度加成（m/s） |
| | 目标锁定框 | 屏幕中心方框 + 角标 + 中心点，随距离接近从 16%→5.5% 屏边收缩，光晕前退场 |
| 穿越 A 55% | DOCKING…→DOCKED 状态灯 | 黄灯闪烁（700ms）→ 绿灯常亮 |
| | 压强读数 | 0→101kPa 数字爬升动画（1.5s easeOut）；退回闸门外自动复位 |
| SEG2 55–75% | 舱内传感器 | 氧气 20.9%（±0.1 微波动）、电力条 55–97%、信号强度条（随进度上升 + 抖动）——持续轻波动，有生命感 |
| 穿越 B 75% | 同步率组件启动 | 集群 boot 闪烁进场 |
| SEG3 75–100% | 打字机文本 | 「信标重启 · 信号将抵达 10,000 光年外」，字符数随 p 0.795→0.935 展开（滚动即打字），每 2 字符微 tick |
| | 光传导同步率 | 0%→100%（p 0.75→0.995）+ 进度条；**100% 达成数字亮起 + 微脉冲 + chime**，退回可再达成 |

### 穿越时刻（进度跨越章界触发一次；±1.5% 窗口内来回跨界不重复，离开窗口后重新武装）

| 时刻 | 组成 |
|---|---|
| A · 对接气闸（55%，光晕①换图峰值） | 增压嘶声 sting + 青白 flash 脉冲（200ms）+ 画面微震（±2px / 150ms）+ HUD 压强爬升 |
| B · 抵达核心（75%，光晕②换图峰值） | 泛音 sting + 暖色 flash + 微震 + 同步率组件启动 |

reduced-motion：无微震无 sting，flash 禁用，HUD 切换 500ms 淡入淡出。

### WebAudio 声音系统（全合成零素材，`js/astra-audio.js`）

- **首次用户手势**（wheel / touch / keydown / pointerdown）才创建 AudioContext（自动播放策略合规；桩测试验证手势前 0 创建）。
- **三床环境音**（章间 800ms 交叉淡化，主增益 0.55）：
  - 真空 SEG1：40Hz + 55.5Hz 推进 hum（0.045/0.018）+ 棕噪低通 90Hz 低鸣 + 无线电杂音（白噪带通 1750Hz Q9 断续突发 0.06–0.28s）+ 星尘沙沙（白噪高通 6.3kHz）
  - 舱内 SEG2：50Hz + 100Hz 电力 hum + 白噪低通 480Hz 通风 + 仪器滴答（1318Hz 短正弦，1.8–4.5s 随机）
  - 核心 SEG3：36Hz 纯低频（慢 LFO 呼吸）+ 泛音垫（110/165/220/330/440/550Hz 正弦叠加，各自慢 LFO 缓慢展开）
- **速度调制**：滚动速度 → 无线电杂音密度（间隔 1.7s → 0.283s @满速）+ 嘶声增益（0.004 → 0.054）。
- **穿越 sting**：A = 白噪高通 420Hz + 1.2s 指数衰减 + 72→44Hz 密封闷响；B = 174.6/261.6/349.2/523.3/784Hz 五泛音错峰缓慢展开 3.4s。
- **UI 音**：导航/进度条 tick（880Hz）、打字机微 tick（1318Hz）、同步达成 chime（659+988Hz 双音）、漫游启停确认（440↔660Hz）。
- **M 键全局静音**：主增益 0.03s 时间常数归零/恢复；右下按钮为状态指示。

### 速度响应

滚动速度（归一化，0.22 进度/秒 = 满速）实时映射到：星尘粒子拉伸系数（v2 引擎既有：`speed*2400` 流迹加成，快滚拉丝，停滚即停）、HUD 数字滚动速率（距离计追赶系数 5→41）、dolly 微颤（canvas 显示层平移 ≤ ±0.9px，运动时钟驱动，不触碰相机数学）、无线电杂音密度与嘶声增益。

### 模块纪律（可测试性）

`astra-hud.js` 的 `logic` 命名空间为纯函数集（无 DOM 依赖）：distanceKm / pressureKpa / climbKpa / syncPct / typedChars / 传感器函数 / `makeTransitGates`（章界门控）。`astra-audio.js` 加载期零副作用。`tests/feedback.test.js`（1193 项断言）覆盖起止值、单调性、有界性、门控触发频次（窗口内震荡仅 1 次）、AudioContext 手势门。

## P2 视频画面层（视频 scrub 优先 · 引擎渲染兜底，`js/astra-video.js`）

滚动进度 0–55% 映射 `seg1-scrub.currentTime`（0→duration）、55–75% 映射 `seg2-scrub`、75–100% 维持引擎渲染（core 漂移 + 晶体点亮不动）。scrub 恒 muted；`currentTime` 跟随 rAF 主循环的**阻尼进度**并按视频实际 duration（6.584s）归一化；高频 seek 以半帧阈值（1/48s）节流，`seeking` 期间只记录 want、`seeked` 落帧后补差（合并）。

### 图层 z 序

| z 序 | 层 | 内容 |
|---|---|---|
| 1（底） | `#vid1` / `#vid2`（absolute 铺满 100vw×100svh、`object-fit:cover`） | 视频主画面（scrub / 漫游连播） |
| 2 | `#scene` canvas（透明画布，`alpha:true`） | scrub 期间只绘反馈层：星尘/薄雾/前景剪影/光晕/压暗幕/暗角/微颤；被视频接管的段不绘主图与背景（避免双影） |
| 3 | `#fade`（z5）/ `#flash`（z6） | 静态模式黑场淡入淡出 / 穿越时刻色温 flash |
| 4（顶） | lockbox(z20) / titles(z30) / progress(z30) / hud(z35) / topbar·tour·mute(z40) | P1 反馈层与 UI（与画面层解耦，零改动） |

引擎侧机制：`AstraVideo` 每帧经 `AstraEngine.setVideoState({a1,a2,present1,present2})` 注入各段"接管权重"；`render()` 用 `plateWeights()` 把被接管的主图权重按 `(1-a)` 让位（视频元素透明度按 `a` 显影，互补和恒 1——测试断言全程无空洞、非堆叠区恒等于 1）。

### 映射与接缝参数

| 参数 | 值 | 说明 |
|---|---|---|
| 段界 | `[0,0.55]` / `[0.55,0.75]` | 与相机时间轴 T1/T2 一致；75–100% 引擎 core 段 |
| 55% 接缝 | `SEAM1 = [0.545,0.555]`（= `TL.SWAP1`） | 两视频在光晕①峰值平台内交叉（seg1 尾帧与 seg2 首帧同构图），权重和恒 1，无黑帧 |
| 75% 接缝 | 引擎 `SWAP2 = [0.745,0.755]` | 引擎 core 交叉权重接管（漫游节奏下约 200ms），藏于光晕②峰值；`CORE_IN = [0.755,0.765]` 后视频淡出并 `display:none` 停止解码 |
| 预载 | `PRELOAD_AT = 0.35` | 进度 >35% 后 fetch seg2 |
| seek 节流 | `SEEK_EPS = 1/48s` | 24fps 半帧阈值 + seeking 合并 |
| 显影 | `REVEAL_MS = 400` | 就绪首次 seek 落帧后 plate→视频交叉淡化（防跳变） |
| 超时 | `TIMEOUT_MS = 8000` | 单段加载总预算；失败链 scrub 版 → 普通压缩版 → 引擎兜底 |

### 加载与回退

`fetch → Blob URL → el.src`（本地 26.6/27.2MB 全关键帧，scrub 任意方向 seek 即时）。任一段 fetch/解码失败、metadata 异常或 8s 超时 → 该段**静默**回退引擎渲染（覆盖率归零，v2 连续相机路径即兜底；仅 console.info 一条开发者日志）。视频显影期间引擎跳过程序化深空兜底底图（不透明填充会盖住视频）；core 剧照缺失时兜底路径照常。

### 自动漫游（45s tour）

漫游中两段视频 **unmuted 正常顺序连播**并接管漫游节奏（视频时间 → 时间轴进度，播完一段接下一段；其后 75–100% 区间从当前进度回 45s 匀速漫游）。全局静音（M）时漫游视频保持静音。漫游中断（滚轮/触摸/按键/导航跳章）→ 立即回 scrub + muted 并 seek 到当前进度；页面不可见时暂停播放、回前台自动续播；`play()` 被自动播放策略拒绝 → 退回匀速漫游。`prefers-reduced-motion` 静态模式：模块禁用（不加载不显影），三个剧照定格位不受影响；移动端 `playsinline`。

### 模块纪律（可测试性）

`astra-video.js` 的 `logic` 命名空间为纯函数集（`segTime` / `base1` / `base2` / `opFor` / `revealAt` / `tourP` / `coveringSeg`）。`tests/video.test.js`（59 项断言）覆盖：映射单调与权重无空洞、0.549→0.551 无跳变（接缝两侧锁定 port 构图）、两段接缝精确对齐、fetch 失败/超时回退（引擎 render 冒烟：无视频绘深空兜底、显影时跳过底填充）、tour↔scrub 状态机（连播/接力/中断 seek 回进度/全局静音/reduced 禁用）。

## 设计说明

- **一个连续世界**：v1 的病根是"三张独立构图 + 交叉淡化"，观感是切换而非镜头运动。v2 的解法是参考链生成同轴素材（approach→port 构图轴线一致），相机沿中轴连续 dolly-in，换图只发生在"画面自己变亮"的时刻——观众的注意力被光吸走，切点不可见。
- **相机即进度**：`AstraEngine.camera(p)` 是纯函数，返回三张剧照各自的 alpha/scale/锚点/微平移与全部氛围参数；可逆（上滚完美倒放）、可测试（tests/continuity.test.js 步进 0.001 断言连续无跳变、换图藏于光晕、主图权重恒和为 1）。
- **时间冻结**：活性动画（星尘摆动、雾团漂移、薄雾呼吸）由"运动时钟 clock"驱动——只有时间轴在移动时钟才前进，停止滚动整幅画面真正冻结。剧照载入后的 0.45s 淡入是一次性展示处理，不属于时间轴特效。
- **兜底**：三张剧照缺失时自动降级为程序化深空（渐变 + 星场 + 星尘 + 光晕），站点不空白；视频层失败时同样回退本引擎。
- **性能**：devicePixelRatio 适配（上限 2）；resize 160ms 防抖重建（忽略移动端地址栏微变，保持时间轴位置）；visibilitychange 暂停 rAF；星尘/雾团/星点数量随屏幕面积缩放；无 shadowBlur，辉光用径向渐变叠加；不使用 ctx.filter（前景软边用多层叠影烘焙）。
- **字体**：系统字体栈，无网络请求。
